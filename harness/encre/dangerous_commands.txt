# ==============================================================================
# Encre Dangerous Command Patterns — Blacklist for terminal operations
#
# Format: one regex pattern per line.
# Section headers: [universal], [linux], [windows], [macos]
# Lines starting with '#' are comments and ignored.
# Empty lines are ignored.
#
# [universal] applies on every host. The other three apply when they match the
# interpreter the command will actually run under: the engine uses the build's
# target OS as the base and additionally enables the family named by the bash
# tool's `terminal` argument (bash/zsh/sh -> linux, powershell/pwsh/cmd ->
# windows), because that argument is model-supplied. Put a rule in [universal]
# when it is about the SHAPE of a command rather than one platform's binaries.
#
# When permission_mode="blacklist", each subcommand produced by the shell
# splitter is tested independently. Any subcommand matching a pattern below
# triggers a permission prompt.
# ==============================================================================

# Same destruction in the shapes the model actually writes. The block above
# hardcodes cmd.exe flag ORDER (`/f` before `/s`) and PowerShell's cmdlet name,
# so `del /q C:\*`, `del /s /q C:\Users`, `Remove-Item -Force -Recurse ...` and
# PowerShell's Unix-style `rm -rf` alias all cleared the table unmatched.
#! severity=critical category=fs
\bdel\s+/s\s+/[a-zA-Z]+\b
\bdel\s+/[a-zA-Z]+\s+/s\b
\bdel\s+/[a-zA-Z]*[qs][a-zA-Z]*\s+[a-zA-Z]:\\+\*
\brm\s+-(?:[a-zA-Z]*r[a-zA-Z]*f|rf|fr)\b
\b(?:Remove-Item|rm|del|erase)\s+.*-Force\b.*-Recurse\b
