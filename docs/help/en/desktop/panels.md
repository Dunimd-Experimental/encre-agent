Besides chat, the session window ships with several built-in tool panels so you don't have to leave the app. Open them via the panel icons next to the session info bar, or with their shortcuts.

## Terminal

A built-in terminal (xterm + node-pty) with:

- **Shell** selector (PowerShell, cmd, bash, etc.)
- **New / kill** terminal instances
- **Send terminal content to the chat** so the agent sees the output
- Works in your project directory for manual commands

![Built-in terminal](/screenshots/panel-terminal.png)

## Editor

A built-in **code editor** (Monaco) with 16+ languages — handy when the agent edits files and you want to review quickly before confirming:

- File tree: new file / folder / delete / paste
- Syntax highlighting

## Review

Git-integrated **review** — review and commit code without leaving chat:

- See **changed files** and diffs (split / unified views, ignore whitespace, word-level diff)
- Distinguish **staged vs unstaged**
- **Commit / push / pull** directly, even open a PR

![Git review panel](/screenshots/panel-review.png)

## Browser

A built-in browser for web automation (search, screenshots, fetching). Supports:

- Back / forward / reload / bookmarks
- Enter a URL or search keyword
- View cookies, history, and site data

Related browser settings, bookmarks, history, and permissions are described in [General](/en/desktop/general).

## Other preview panels

Depending on the content, you may also use:

- **Markdown / code preview**
- **Media preview** (images, audio, video)
- **Office document preview**

> [!TIP]
> Panels can be collapsed. Panel-related shortcuts are listed in [Shortcuts](/en/desktop/shortcuts).
