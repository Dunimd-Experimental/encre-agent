The app's overall behavior is configured in **Settings → General**. This page covers the common options.

## Appearance

| Option | Description |
| --- | --- |
| Theme | Follow system / Light / Dark |
| Language | UI language (Chinese / English) |

## Input & interaction

| Option | Description |
| --- | --- |
| Send with | `Enter` to send / `Ctrl+Enter` to send |

## Startup

| Option | Description |
| --- | --- |
| Startup mode | The mode opened by default |
| Restore session on startup | New / restore last session |
| Auto-start | Launch the app at login |

## Links & replies

| Option | Description |
| --- | --- |
| Local link default open | System browser / open in app / system app |
| Reply language | Default language of the agent's replies |

## User profile

Encre Agent infers a "user profile" (basic / communication / tech / behavior etc.) from how you use it, so replies fit your preferences. This is generated locally and can be managed as needed.

![General settings panel](/screenshots/general-settings.png)

## Browser settings

Default search engine, bookmarks, history, cookies, per-site permissions and site data for browser automation are managed in the browser settings area (with import from Chrome / Edge / Firefox).

When browser automation is needed, the app guides you to install Playwright's Chromium engine (≈200MB download) or use local Edge's CDP / WebDriver.

> [!TIP]
> Theme and language changes apply immediately, no restart needed. Shortcuts are customized in [Shortcuts](/en/desktop/shortcuts).
