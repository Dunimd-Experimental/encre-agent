Global search finds almost everything in one place: conversations, files, memory, settings, and commands.

## Opening search

- Click the **Search** button at the top
- Or press `Ctrl+K` (`Cmd+K` on macOS)

## What you can search

Global search covers the following types:

| Type | Description |
| --- | --- |
| Conversations | Session titles and content |
| Files | File names in workspaces |
| Sessions | Historical session titles |
| Memory | Entries in the memory store |
| Rules | Global and project rules |
| Skills | Installed skills |
| Workspaces | Workspace names |
| Models | Configured model names |
| MCP servers | Connected MCP services |
| Sub-agents | Configured agents |
| Documents | Documents in the library |
| Settings | Settings panels and entries |
| Actions | Various app actions |
| Slash commands | Built-in and custom commands |
| Tools | Available tool names |
| Automation | Automation tasks |
| Workflows | Workflow items |

After typing a keyword, results are grouped by type; click one to jump to the matching place.

## Search filters

Too broad? In **Settings → Search Filter**, tick/untick the categories to search so only the types you need appear.

## Tips

- Hit `Ctrl+K` / `Cmd+K` anytime — no mouse needed
- Searching the "Settings" type is a fast way to reach any settings panel
- Searching "Actions" runs corresponding app actions (e.g. new session)
- For files, search matches names inside your workspaces; ask the agent to grep the folder when you need contents
