Almost every action can be bound to a keyboard shortcut, and **all of them are customizable**. View and change them under **Settings → Shortcuts**.

## Recommended defaults

| Action | Default |
| --- | --- |
| Global search | `Ctrl+K` |
| Open settings | `Ctrl+,` |
| New session | `Ctrl+L` |
| Close / collapse | `Escape` |
| Send message | `Enter` |
| New line | `Shift+Enter` |

## Customizing shortcuts

1. Open **Settings → Shortcuts**
2. Browse by category (App / Session / Message / Input / Mode / Navigation / Search / Settings / Panels / Automation / Workspace / Notifications / Appearance / General)
3. Click a command and press the new key combination to bind it
4. If it conflicts with another command, you'll be prompted
