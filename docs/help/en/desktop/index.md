Welcome to **Encre Agent Desktop** — an AI agent that lives on your desktop.

Encre Agent is a local AI agent platform. It is not just a chat tool — it can actually **roll up its sleeves and do things for you**: read and write files, run commands, browse the web, manage code, run scheduled tasks, and push results to the chat platforms you already use.

## What it can do

**One conversation, many jobs done.** Whether you want to chat, write code, do market research, watch stock prices, or get a news briefing every morning — just describe it to Encre Agent in natural language.

**Multiple ways to work.** Encre Agent is conversation-first, with three working modes:

| Mode | Use case |
| --- | --- |
| **General** | Everyday chat, questions, problem analysis |
| **Work (iWork)** | Working on a specific folder / code project |
| **Automation** | Scheduled tasks that run and push results |

## Core capabilities

### A local assistant that acts
- **Files & commands**: read, write, edit files; run terminal commands
- **Browser**: search the web, fetch information, drive a real browser
- **Memory**: remembers your preferences across sessions and gets better over time
- **Multi-agent**: multiple specialized agents cooperate on complex tasks

### A platform that uses tools
- **84+ built-in tools**: files, terminal, browser, databases, Git, Docker, email, image generation, OCR, and more
- **MCP (Model Context Protocol)**: connect third-party capabilities
- **Swarm multi-agent system**: agents cooperate on a shared blackboard

### Connected without limits
- Support for **31 major LLM providers**, all managed in one app
- Connect **26+ chat platforms**: Telegram, QQ, WeChat, Discord, DingTalk, Feishu, Slack, Email, WhatsApp, Signal … wherever you are, it is there

### Safe to trust it
- **6 permission modes**: ask-first by default, bypass, auto-allow, allow-edits, and more
- **SSRF protection** (DNS + CIDR blacklist), **Docker sandbox** + Linux Landlock
- **AI risk classifier** and rate limiting
- Local data encrypted with **AES-256-GCM**
