The About page has version info, legal terms, data rules, and official channels. Open it via **Settings → About**.

## Version info

- App name: **Encre Agent Desktop**
- Current version: `0.5.0`
- Data directory: where your data lives
- Cache size: current cache usage

## Check for updates

Click **Check for updates** to get the latest version.

## Legal

The page provides links to **License / Privacy Policy / Terms of Service / Thanks** etc.

## Region & data rules

- **Region picker**: choose applicable data rules by region (Americas / Europe / Asia & Middle East / Africa / Oceania) and specific countries
- **Data rules**: default data-handling practices per region
- **Minors privacy**: minor privacy protection statement
- Mainland China filing info (ICP record) is shown here too

## Feedback & support

Official entry points include:

- Official docs
- Report a bug

## Log viewer

Click **View logs** to open the log viewer for troubleshooting. Log files also live in the local data directory.

## Hidden developer mode

> [!NOTE]
> "Developer mode" is hidden by default. Tap the version number multiple times on the About page to unlock it. Once unlocked, press `F12` to open DevTools, and you can force-restart the server/app. It's for advanced users — usually not needed.
