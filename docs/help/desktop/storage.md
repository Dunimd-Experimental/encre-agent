数据都保存在本地。在 **设置 → 存储** 中查看数据目录、管理会话数据，以及导入导出全部数据。

## 数据目录

页面顶部展示应用数据目录位置。所有会话、记忆、设置等数据都存于该目录，你的本地数据默认使用 **AES-256-GCM 加密**。

## 清除与删除

| 操作 | 说明 |
| --- | --- |
| 清除全部会话 | 删除所有会话记录 |

> [!WARNING]
> 清除会话不可恢复，执行前请确认已导出需要的内容。

## 导出全部数据

把全部数据导出为一个解密后的整体压缩包（不会包含日志与密钥）。

- 适合备份、迁移到另一台电脑
- 导出前建议确认存放位置安全

## 导入全部数据

导入之前导出的数据。提供三种合并方式：

| 方式 | 说明 |
| --- | --- |
| 覆盖合并（推荐） | 用导入数据覆盖现有同名数据，其余保留 |
| 清空并替换 | 先清空现有数据再全部导入 |
| 跳过已有文件 | 只导入本地没有的数据 |

> [!NOTE]
> 导入的数据会以当前机器的密钥重新加密。

## FAQ

**问：导出包包含密钥吗？**
答：不会。导出的数据不包含日志与密钥。

**问：数据会在云端吗？**
答：会话与设置数据保存在本地数据目录。只有你主动配置的网关/模型调用会与对应服务通信。
