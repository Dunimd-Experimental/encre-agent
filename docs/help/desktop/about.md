关于页面包含版本信息、法律条款、数据规则与官方渠道。在 **设置 → 关于** 中打开。

## 版本信息

- 应用名称：**Encre Agent Desktop**
- 当前版本：`0.5.0`
- 数据目录：展示数据存放位置
- 缓存大小：查看缓存占用

## 检查更新

点击「检查更新」即可获取最新版本。

## 法律条款

页面提供 **许可证 / 隐私政策 / 服务条款 / 致谢** 等法律文档入口。

## 地区与数据规则

- **地区选择器**：按地区（美洲 / 欧洲 / 亚洲与中东 / 非洲 / 大洋洲）与细分国家选择适用的数据规则
- **数据规则**：不同地区默认的数据处理方式
- **未成年人隐私**：未成年人隐私保护说明
- 中国区备案信息（ICP 备案号）也会在此展示

## 反馈与支持

页面提供官方入口：

- 官方文档
- 报告 Bug
- 社区
- 联系我们

## 日志查看器

点击「查看日志」打开日志查看器，便于排查问题。日志文件也会保存在本地数据目录。

## 隐藏的开发者模式

> [!NOTE]
> 「开发者模式」默认隐藏。在关于页面连续点击版本号多次即可解锁。解锁后可按 `F12` 打开开发者工具，并可强制重启服务器/应用。该功能面向高级用户，一般无需使用。
