Encre Agent 顶部有一个三档模式切换器。你可以随时切换，不需要退出或重启。

| 模式 | 场景 | 侧边栏/额外功能 |
| --- | --- | --- |
| 通用 | 日常对话、分析、提问 | 基础会话 |
| 工作 (iWork) | 在项目文件夹上工作 | 工作区、代码补全 |
| 自动化 | 定时任务 | 自动化任务管理 |

![顶部的模式切换器](/screenshots/mode-switcher.png)

## 通用模式

默认模式。适合日常提问、头脑风暴、资料分析等不依赖具体文件夹的任务。

- 你可以直接 @ 上传文件让 Agent 阅读
- 侧边栏展示「全部任务」的会话列表
- 适合任何没有明确项目上下文的对话

## 工作（iWork）模式

在工作区打开一个文件夹后，Agent 才能真正"看懂"你的项目：

- **工作区**：将一个本地文件夹注册为工作区，Agent 会在其中读写文件、运行命令
- 打开文件夹的方式：侧边栏 → 工作区 → 打开文件夹，或使用快捷键（详见 [快捷键](/desktop/shortcuts.md)）

![工作模式下打开文件夹](/screenshots/workspace-open-folder.png)

详见 [工作区](/desktop/workspace.md)。

## 自动化模式

把重复性的工作交给定时任务：

- 创建基于模板或自定义的定时任务（日报、周报、舆情监控、股价预警等）
- 配置触发时间与执行模型
- 执行结果可推送到网关平台（Telegram、邮件等）

![自动化模式概览](/screenshots/automation-overview.png)

详见 [自动化任务](/desktop/automation.md)。

> [!NOTE]
> 三种模式共用同一个应用与账号体系，切换只是改变当前工作方式，不会丢失历史会话。
