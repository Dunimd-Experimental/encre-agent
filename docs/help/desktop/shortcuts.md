几乎每个操作都可以绑定快捷键，并且**全部可自定义**。在 **设置 → 快捷键** 中查看与修改。

## 推荐默认

| 用途 | 默认 |
| --- | --- |
| 全局搜索 | `Ctrl+K` |
| 打开设置 | `Ctrl+,` |
| 新建会话 | `Ctrl+L` |
| 关闭 / 收起 | `Escape` |
| 发送消息 | `Enter` |
| 换行 | `Shift+Enter` |

## 自定义快捷键

1. 打开 **设置 → 快捷键**
2. 按分类浏览（应用 / 会话 / 消息 / 输入 / 模式 / 导航 / 搜索 / 设置 / 面板 / 自动化 / 工作区 / 通知 / 外观 / 通用）
3. 点击某条命令，按下新的组合键即可绑定
4. 若与其他命令冲突，会提示你处理
