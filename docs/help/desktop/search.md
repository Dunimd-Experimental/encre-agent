全局搜索让你在一个地方找到应用里的几乎所有内容：对话、文件、记忆、设置、命令，都能搜。

## 打开搜索

- 点击顶部的**搜索**按钮
- 或按快捷键 `Ctrl+K`（macOS 为 `Cmd+K`）

## 能搜到什么

全局搜索覆盖以下类型：

| 类型 | 说明 |
| --- | --- |
| 对话 | 会话标题与内容 |
| 文件 | 工作区内的文件名 |
| 会话 | 历史会话的标题 |
| 记忆 | 记忆库中的条目 |
| 规则 | 全局规则与项目规则 |
| 技能 | 已安装的技能 |
| 工作区 | 工作区名称 |
| 模型 | 已配置的模型名称 |
| MCP 服务器 | 已接入的 MCP 服务 |
| 子智能体 | 已配置的智能体 |
| 文档 | 资料库中的文档 |
| 设置 | 设置面板与条目 |
| 动作 | 各种应用动作 |
| 斜杠命令 | 内置与自定义命令 |
| 工具 | 可用的工具名称 |
| 自动化 | 自动化任务 |
| 工作流 | 工作流相关 |

输入关键词后，结果会按类型分组展示，点击即可跳转到对应位置。

## 搜索过滤

搜索覆盖太广？可以在 **设置 → 搜索过滤** 中勾选/取消勾选要搜索的类别，只保留你需要的类型，让结果更精准。

## 小技巧

- 使用 `Ctrl+K` / `Cmd+K` 随时唤起，不必用鼠标
- 搜索「设置」类型可以快速到达某个设置面板
- 搜索「动作」可以执行对应应用动作（如新建会话）
- 想找文件时，搜索会匹配工作区内的文件名；需要看内容时让助手直接检索目录
