应用的整体行为在 **设置 → 通用** 中配置。这里描述常见的选项。

## 外观与显示

| 选项 | 说明 |
| --- | --- |
| 主题 | 跟随系统 / 浅色 / 深色 |
| 语言 | 界面语言（中文 / English） |

## 输入与交互

| 选项 | 说明 |
| --- | --- |
| 快捷键发送方式 | `Enter` 发送 / `Ctrl+Enter` 发送 |

## 启动行为

| 选项 | 说明 |
| --- | --- |
| 启动时的模式 | 打开应用默认进入的模式 |
| 启动时恢复会话 | 新建 / 恢复上次的会话 |
| 开机自启动 | 登录后自动启动应用 |

## 链接与回复

| 选项 | 说明 |
| --- | --- |
| 本地链接默认打开方式 | 系统浏览器 / 应用内打开 / 系统应用 |
| 回复语言 | Agent 默认用什么语言回复 |

## 用户画像

Encre Agent 会根据你的使用习惯自动推断「用户画像」（基础 / 沟通 / 技术 / 行为等），用于让回复更贴合你的偏好。该信息在本地自动生成，也可在需要时手动管理。

![通用设置面板](/screenshots/general-settings.png)

## 浏览器相关设置

浏览器自动化相关的默认搜索引擎、书签、历史、cookie、每个站点的权限与站点数据，都可以在浏览器设置区域管理（可导入 Chrome / Edge / Firefox 的书签与历史）。

需要代理浏览器自动化时，应用会引导你安装 Playwright 的 Chromium 引擎（下载约 200MB）或使用本机 Edge 的 CDP / WebDriver。

> [!TIP]
> 修改主题与语言即时生效，无需重启。快捷键的自定义在 [快捷键参考](/desktop/shortcuts.md)。
