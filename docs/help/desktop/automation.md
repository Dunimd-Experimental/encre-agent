自动化模式让重复性工作按计划自动执行，并把结果推送给你。适合日报、监控、扫描这类"每天盯着"的苦差事。

## 进入自动化

点击顶部切换到「自动化」模式，即可看到自动化页面，包含两个标签页：

- **已配置**：你创建的所有任务列表
- **执行历史**：每次执行的记录与结果

## 创建任务

点击「新建任务」，按模板或自定义创建：

**内置模板**

| 模板 | 用途 |
| --- | --- |
| 每日 AI 新闻简报 | 每天定时汇总 AI 领域新闻 |
| 品牌舆情监控周报 | 每周生成品牌舆情周报 |
| 每周竞品动态追踪 | 追踪竞品最新动态 |
| 股价监控与预警 | 监控股价并在异动时预警 |
| 安全漏洞扫描 | 定期扫描安全隐患 |
| 扫描提交发现 Bug | 扫描代码提交发现潜在 Bug |
| 补充测试覆盖 | 分析并补充测试覆盖 |
| 每日变更摘要 | 汇总项目每日变更 |

也可以选择「自定义创建」，完全按你的提示词定义任务。

## 配置任务的字段

| 字段 | 说明 |
| --- | --- |
| 任务名称 | 便于识别的名称 |
| 触发计划 | 多久执行一次：每天 / 每周 / 每小时 / 工作日 / 自定义 / 单次 / 每分钟 |
| 执行模型 | 运行该任务使用的模型 |
| 启用推送 | 勾选后把执行结果推送到「目标网关」 |
| 目标网关 | 选择已配置的网关渠道（如 Telegram、邮件） |
| 执行内容 | 告诉 Agent 具体做什么 |

## 管理任务

在「已配置」列表中，每个任务提供：

- **立即执行**：立刻手动运行一次（无需等待计划时间）
- **开启 / 暂停**：暂停后任务不会触发，但保留配置
- **删除**：移除任务
- **查看历史**：进入该任务的执行记录

## 执行历史

在「执行历史」标签页可以：

- 按结果过滤（全部 / 成功 / 失败）
- 按日期范围筛选（起止日期）
- **导出**执行记录
- 查看每次执行的状态：运行中 / 已暂停 / 等待中 / 成功 / 失败
- 点击某次执行可**返回对话**查看 Agent 完整执行过程

## 常见问题

**问：执行失败怎么办？**
答：在历史中点击该次执行「返回对话」，查看失败原因。常见错误码：`-1` 表示 Bash 执行超时，`-2` 表示未安装 Docker。

**问：没有网关也能用自动化吗？**
答：可以。推送是可选项，不配置推送也能正常执行；只是结果不会推送到聊天工具。配置方法见 [网关接入](/desktop/gateway.md)。

**问：任务会消耗大量资源吗？**
答：任务在计划到点时才会运行，且受权限系统管控。建议把任务模型与对话模型分开，避免相互影响。
