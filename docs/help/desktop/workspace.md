工作区（iWork）模式让 Encre Agent 在一个本地文件夹内工作，是写代码、整理文档、跑项目任务的最佳方式。本页介绍工作区的创建与管理。

> [!NOTE]
> 只有切换到底部「工作」模式后，侧边栏才会出现「工作区」区域。

## 打开 / 创建工作区

1. 切换到「工作」模式
2. 在侧边栏「工作区」区域点击「新建工作区」或「打开文件夹」
3. 选择本机任意文件夹

打开后应用会：
- 把该文件夹注册为工作区并显示在侧边栏
- 展示该工作区内已有的会话数量。

![新建工作区](/screenshots/workspace-create.png)


## 工作区设置

在侧边栏工作区上点击「设置」可以：

- **重命名**工作区（仅影响显示名，不影响磁盘路径）
- **上传图标**自定义工作区显示图标
- 查看**路径**、**ID**、**会话数量**
- **移除工作区**（不删除磁盘文件，只是从应用解除关联）

## 归档管理

不常用但重要的项目可以**归档**：会话列表不再显示，随时可从「归档管理」中**移出归档**恢复。归档的会话不会丢失。

![归档管理面板](/screenshots/workspace-archive.png)

## 在工作区中工作

打开工作区后，在输入框直接描述任务即可，例如：

- 「阅读 README，总结这个项目的技术栈」
- 「修复 tests 目录下运行失败的单元测试」
- 「重构 `src/util.ts`，并保持接口不变」
- 「检查代码质量并输出报告」

Agent 会自行浏览项目、读取文件、运行命令、修改代码，并在回答中引用 `文件路径:行号` 方便你核对。

![工作区中 Agent 引用文件](/screenshots/workspace-chat.png)

## 常见问题

**问：打开工作区后没有反应？**
答：确认模型已配置（见 [模型管理](/desktop/models.md)）。

**问：移除工作区会影响磁盘上的文件吗？**
答：不会。移除只是解除应用关联，磁盘文件不会删除。删除工作区会话才是删除会话本身。

**问：一个文件夹能注册为多个工作区吗？**
便于会话管理
