会话窗口除了对话，还内置了多个工具面板，方便你在不切出应用的情况下完成更多操作。打开方式：点击会话信息栏旁的面板图标或使用对应快捷键。

## 终端

内置终端（基于 xterm + node-pty），支持：

- 选择**Shell**（如 PowerShell、cmd、bash 等）
- **新建 / 终止**终端实例
- 把终端内容**发送到对话**，让 Agent 看到输出
- 与你的项目目录联动，方便手动执行命令

![内置终端](/screenshots/panel-terminal.png)

## 编辑器

内置**代码编辑器**（基于 Monaco），支持 16+ 种语言，适合让 Agent 编辑文件后由你快速浏览再确认：

- 文件树浏览：新建文件 / 文件夹 / 删除 / 粘贴
- 语法高亮

## 审查（Review）

接入 **Git**，在对话中就能完成代码审查与提交：

- 查看**改动文件**与 diff（支持**分栏 / 合并**视图、忽略空白、逐词比较）
- 区分**暂存 / 未暂存**
- 直接**提交 / 推送 / 拉取**，甚至创建 PR

![Git 审查面板](/screenshots/panel-review.png)

## 浏览器

内置浏览器供 Agent 进行网页自动化（如搜索、截图、抓取）。支持：

- 前进 / 后退 / 刷新 / 书签
- 输入网址或搜索关键词
- 查看 cookies、历史记录、站点数据

相关设置与书签/历史/权限管理见 [通用设置](/desktop/general.md) 中的浏览器说明。

## 其他预览面板

对话中出现相关结果时，还可能用到：

- **Markdown / 代码预览**
- **媒体预览**（图片、音视频）
- **Office 文档预览**

> [!TIP]
> 面板都可以收起。快捷键与面板相关的条目见 [快捷键参考](/desktop/shortcuts.md)。
