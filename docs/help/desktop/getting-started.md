跟着这一步一步的指引，你将在 5 分钟内跑通 Encre Agent Desktop 并在第一段对话中看到它真正动手干活。

## 第一步：安装与启动

1. 下载适合你系统的安装包并完成安装
   - **Windows**：`.exe`（NSIS 安装包）
   - **macOS**：`.pkg`
   - **Linux**：`.deb` / `.rpm`
2. 安装完成后启动 Encre Agent Desktop，你会看到主界面和欢迎页。

![启动后的主界面](/screenshots/launch-window.png)

## 第二步：配置模型

没有可用的模型，Agent 无法工作。打开左侧边栏底部的 **设置 → 模型**：

1. 点击「新建」添加一个模型
2. 填写：
   - **显示名称**：随便起一个你记得住的名字，例如 `DeepSeek`
   - **模型 ID**：模型标识，例如 `deepseek-chat`
   - **服务商**：选择或填写模型提供方
   - **API 密钥**：粘贴你的密钥（在服务商平台创建）
   - **Base URL**：接口地址，一般会自动拼接 API 路径
   - **最大 Token**：单次回复的最大输出长度
3. 如果模型支持图片等多模态输入，打开「多模态能力」开关（保存时会验证）
4. 点击「保存」

> [!TIP]
> 不同模型对「思考/推理等级」的支持不同。请在模型设置中为支持的模型启用「推理等级」，输入框右侧可选择。设置页也提供「获取 API 密钥」和「查看文档」入口。

## 第三步：发起第一段对话

1. 在最底部的输入框中输入一句话，例如：
   - 「帮我写一个 Python 脚本，把当前目录下所有 .txt 文件合并成一个文件」
2. 点击**发送**按钮（或按 `Enter`）
3. 观察右侧的**工具调用卡片**：Agent 会依次执行 `Bash`、`Write File` 等工具，并把结果展示给你
4. 回复里会显示文件路径、命令输出等真实信息，方便你核对

![第一段对话与工具调用](/screenshots/first-chat-toolcalls.png)

## 第四步：尝试一个更复杂的任务

在**工作区**模式下打开一个文件夹，然后对 Agent 说出你的需求（例如「扫描这个项目的代码质量，并输出报告」）。它会：

- 主动浏览项目结构
- 阅读相关文件
- 执行命令验证
- 给出带文件引用的回答

具体用法见 [工作区](/desktop/workspace.md) 页面。
