对话是 Encre Agent 的核心。这里介绍如何高效组织会话、管理消息，以及理解 Agent 的行动过程。

## 会话（Session）

每次点击「新会话」都会创建一个独立的会话，会话之间的上下文互不影响。会话支持多种操作：

| 操作 | 说明 |
| --- | --- |
| 重命名 | 给会话起一个有意义的名称，方便日后查找 |
| 导出为 Markdown | 把整个会话导出为 `.md` 文件 |
| 归档 | 归档的会话从列表隐藏，可随时恢复 |
| 删除 | 永久删除该会话（存在批量选择删除） |
| 批量操作 | 在「全部任务」中选择多个会话批量导出/删除 |

### 会话侧边栏
侧边栏展示所有会话。你可以：
- 点击会话切换
- 使用快捷键 `Ctrl+L` 新建会话
- 随时搜索会话历史

![会话侧边栏与操作菜单](/screenshots/session-sidebar.png)

## 临时对话

不需要长期保存？使用「临时对话」——它会在退出时自动清空，适合快速、不重要的问答。

> [!NOTE]
> 临时对话的内容不会写入持久历史，请复制需要的部分。

## 消息操作

把鼠标悬停在任意一条消息上，会出现操作按钮：

- **编辑**：修改这条消息后重新发送
- **复制**：复制为纯文本
- **复制 Markdown**：复制为 Markdown 源码
- **删除**：移除该消息
- **回滚编辑**：撤销这一条消息并删除其后的所有回复，回到它之前的状态

### 重新生成回复
回复被中断或你想换个角度时，可以使用：
- **重新生成**：按默认配置重新生成
- **更详细**：生成更长的回复
- **更简洁**：生成更短的回复

### 分支
在任一条助手消息上可以选择创建**分支**。分支会在该消息处产生一个全新的后续，而不影响原回复。适合想保留当前结果、同时探索另一个方向的场景。

## 输入区

底部输入框是主要入口：

- **@ 上传文件**：附加文件/文件夹让 Agent 读取
- **斜杠命令**：输入 `/` 可唤起命令菜单
- **选择模型**：切换当前会话使用的模型
- **选择推理等级**：当模型启用「深度思考」时可切换思考深度（默认 / 更深入）
- **发送 / 停止**：发送消息（`Enter`），或在生成过程中停止（`Shift+Enter` 换行）

### 内置命令

| 命令 | 作用 |
| --- | --- |
| `/plan` | 计划模式：先制定计划、准备好后再执行 |
| `/spec` | 规格模式：实现之前先编写规格 |
| `/new-session` | 新建会话 |
| `/clear-session` | 清除当前会话内容 |
| `/init` | 初始化项目：扫描项目结构并生成 `AGENTS.md` |

自定义命令见 [技能与命令](/desktop/skills.md)。

## 理解 Agent 的行动：工具调用卡片

Agent 会使用工具来完成任务。每条工具调用会显示为一张卡片，可以看到工具名称、参数和实时状态：

- 状态有：排队中 → 运行中 → 成功 / 失败
- 常用工具卡片：Bash/Shell/Terminal、Web Search、Web Fetch、Find Tool、Read File、Write File、Edit File、Apply Patch、MCP、LSP、Git、Memory、Task、Cron、Rest Client、Desktop 等

如果看到多张卡片同时运行，说明 Agent 正在执行**并行任务**；排队中的卡片会显示「排队中 {n} 个提示等待中」。

![一串工具调用卡片](/screenshots/tool-cards.png)

### 深度思考（思维条）
使用了推理模型的会话中，消息上方会显示可收起的「深度思考」条。点击可以展开查看 Agent 的推理过程，方便你理解它的思路。

### 计划 / 规格组件
在 `/plan` 或 `/spec` 模式中，回复会以可勾选的任务列表（计划）或结构化规格展示。

## 错误与重试

当请求失败时，回复区会显示错误类型卡片，包括：

- **速率受限**（Rate limited）：请求太频繁或配额用尽
- **上下文超限**（Context overflow）：内容超过了模型上下文窗口
- **网络错误**、**服务器错误**、**工具错误**、**已中断**

多数情况下你只需重试一次；若是「上下文超限」，可尝试开新会话或让 Agent 总结后用「更简洁」重来。

> [!TIP]
> 会话里创建的文件会标注为「产物」，在会话信息面板中可以查看本次对话生成了多少产物。
