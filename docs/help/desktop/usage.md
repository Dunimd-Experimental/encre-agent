用量统计让你掌握模型消耗与使用习惯。在 **设置 → 用量统计** 中查看。

## 总体指标

页面顶部展示核心累计数据：

- **会话总数**
- **Token 总量**（输入 / 输出）
- **工具调用次数**

## 多维视图

- **按模型 / 按会话**：查看不同模型或会话的用量分布
- **每日用量**（堆叠图）：观察每天消耗趋势
- **Token 趋势**：输入/输出 Token 随时间变化
- **按模式**：通用 / 自动化 分别消耗

## 活跃度热力图

「活跃度热力图」展示你的连续使用情况：

- 活跃天数与连续打卡（streak）
- 高频时段（每个小时的使用强度）
- 峰值情况

![用量统计](/screenshots/usage-panel.png)

## 用途建议

- 了解哪家模型消耗最多，决定是否调整默认模型
- 观察到 Token 趋势陡增时，检查是否有自动化任务在大量运行（见 [自动化](/desktop/automation.md)）
- 对照 [模型管理](/desktop/models.md) 合理分配不同任务的模型

> [!NOTE]
> 统计数据来自本地，重新导入导出数据会随之更新。
