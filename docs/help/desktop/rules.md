规则是 Agent 必须遵守的约束。在 **设置 → 规则** 中，分「全局规则」和「项目规则」两类。

## 全局规则

适用于所有会话，存放在 `~/.dunimd/encre/rules/` 目录。适合放置通用的行为约束，例如：

- 回答问题时先给出结论再展开
- 涉及敏感操作前说明你的计划
- 统一用中文回复（如果不希望用中文回复）

## 项目规则

只对当前工作区生效，例如：

- `.encre/rules.md`：Encre Agent 优先读取的项目规则
- 也会自动识别 `.cursorrules`、`.clinerules` 等生态惯例文件

适合放项目专属约定，比如：

- 代码风格与规范（使用空格缩进、单引号、ESM）
- 「不要修改 `dist/` 目录」
- 「提交信息使用 Conventional Commits」

## 编辑规则

- 打开规则列表，点击规则即可编辑内容
- 保存后自动生效（无需重启）

> [!NOTE]
> 全局规则与项目规则是**强制约束**，同时生效。当两者冲突时，在提示词中通常以项目规则优先，具体取决于会话上下文。

## 规则的作用方式

规则会注入到 Agent 的每次会话上下文中。生效的规则数量会影响上下文占用，建议保持精简、聚焦。

## FAQ

**问：规则不生效？**
答：检查是否保存、文件路径是否正确；项目规则确认它对应当前工作区。

**问：想在某个项目临时关闭全局规则？**
答：规则是全局绑定的。如需更精细控制，可在对话中说明「本会话忽略某规则」。真正想要隔离时，建议使用独立的工作区并在项目规则中写明例外。
