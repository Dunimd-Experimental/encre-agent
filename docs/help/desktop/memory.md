记忆让 Encre Agent 跨会话持续记住重要信息，越用越懂你。在 **设置 → 记忆** 中查看和管理。

## 记忆是什么

Encre Agent 的持久记忆以带元数据的 Markdown 文件存储，每条记录包含：

- 名称 / 标题
- 内容预览
- 附加信息（创建时间、更新时间、重要程度等）

Agent 会**主动写入**它认为值得记住的内容（比如你的偏好、项目背景），并在之后需要时引用。

## 查看与刷新

- 打开 **设置 → 记忆** 可浏览全部记忆条目
- 点击查看详情
- 需要时点击**刷新**获取最新状态

## 记忆的分层

Encre Agent 内部区分**工作记忆**（当前会话/任务相关）与**长期记忆**（跨会话沉淀）。配合**智能衰减**机制，低重要度的旧条目会自动老化，避免上下文膨胀。

## 记忆的智能特性

- **语义搜索**：Agent 检索记忆时按语义匹配，而非简单关键词
- **自动老化**：重要程度低、长期未用的条目逐步降权
- **主动沉淀**：任务结束后自动总结值得保留的信息

## FAQ

**问：记忆会被其他会话看到吗？**
答：记忆是共享的，便于跨会话为你服务。若某信息不希望进入长期记忆，可在对话中明确「不要记住这个」。

**问：记忆占用空间吗？**
答：单条记录很小；应用会定期整理与老化。存储相关的空间说明见 [存储与数据](/desktop/storage.md)。

**问：能手动删除某条记忆吗？**
答：在记忆列表中删除对应条目即可。

> [!TIP]
> 想让 Agent 牢牢记住某件事，直接在对话里说：例如「请记住：我偏好使用 TypeScript 编写项目」。
