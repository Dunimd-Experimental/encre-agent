智能体（子智能体 / sub-agents）是以不同系统提示词运行的专属 Agent。把固定职责交给专门的智能体，可以让主 Agent 分工更清晰。

## 新建智能体

在 **设置 → 智能体** 中点击「新建」，配置：

| 字段 | 说明 |
| --- | --- |
| 名称 | 用于在对话中引用（如 `code-reviewer`） |
| 系统提示词 | 定义这个智能体的角色与行为规则 |

例如创建一个 `code-reviewer`：
- 名称：`code-reviewer`
- 提示词：`你是资深代码审查员，关注安全性、可维护性与潜在缺陷，给出分级修改建议。`

保存后，主 Agent 在处理相关任务时会考虑启用合适的智能体协助。

![智能体管理](/screenshots/agents-list.png)

## 使用方式

- 在对话中描述需求时，说明需要哪个智能体参与，例如「让 code-reviewer 审查这段代码」
- 也可以直接创建跟当前任务无关的小助手，按角色使用

## 内置 Agent 角色

Encre Agent 预置了多套角色分工，会在不同场景自动配合：

- **通用**：coder（编码）、researcher（研究）、critic（批评与审查）
- **工作区**：architect（架构）、planner（规划）
- **计划/规格**：spec-writer（规格编写）
- **自动化**：monitor（监控）、executor（执行）、scheduler（调度）

## 会话信息里的 Agent 配置

当前会话使用的智能体配置（专长、权限模式、最大轮数、发送方式）可以在会话信息面板查看，方便你了解该会话以何种角色运行。

> [!TIP]
> 每个智能体都受 [权限与安全](/desktop/permissions.md) 的全局管控，即使智能体分工再明确，危险操作依然要先征求你同意。
