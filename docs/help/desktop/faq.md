这里汇总使用 Encre Agent Desktop 时最常遇到的问题。

## 通用

**问：如何开始使用？**
答：先安装应用 → 配置模型（设置 → 模型）→ 在输入框提问。详见 [快速上手](/desktop/getting-started.md)。

**问：Agent 说没有可用模型？**
答：在设置 → 模型中添加一个模型（含 API 密钥、模型 ID、Base URL）。获取密钥入口见 [模型管理](/desktop/models.md)。

**问：Agent 不回复 / 一直转圈？**
答：检查网络与模型配额。详情查看回复区域显示的错误类型卡：速率受限、上下文超限、网络错误、服务器错误、工具错误等。

## 对话与会话

**问：临时对话和普通会话有什么区别？**
答：临时对话退出后自动清空，适合快速问答；普通会话会持久保存。

**问：误删了一条消息能找回吗？**
答：单条删除后可用「撤销」快捷键恢复上一步操作；整会话删除前建议先「导出为 Markdown」。

**问：回复太长了或被打断怎么办？**
答：使用「重新生成 / 更简洁」重新生成，或用「停止」后接着提问。

**问：上下文超限了？**
答：新建会话、或让 Agent 先总结当前结论再继续。时不时启用侧的「压缩」可自动整理上下文。减少上下文占用也可从精简[规则](/desktop/rules.md)入手。

## 工作区


**问：移除工作区会删文件吗？**
答：不会。移除只是解除应用关联，磁盘文件保留。删除会话才是删除会话记录。

## 自动化

**问：自动化任务失败？**
答：进入该任务的「执行历史」，点击该次执行返回对话查看原因。常见错误码：`-1` Bash 超时、`-2` 缺少 Docker。

**问：任务没有按时执行？**
答：检查任务是否处于「已暂停」状态、计划配置是否正确、以及应用当时是否在运行。

**问：结果推送到哪里？**
答：在任务配置中启用「推送」并选择目标网关（如 Telegram、邮件）即可。配置见 [网关接入](/desktop/gateway.md)。

## 权限与安全

**问：为什么 Agent 经常问我要不要执行命令？**
答：默认权限模式为保证安全，危险操作每次先征求同意。如信任当前任务，可在 [权限与安全](/desktop/permissions.md) 中调整策略或权限模式。

**问：权限设置怎么恢复出厂？**
答：权限面板点击「重置默认值」。

**问：数据安全吗？**
答：本地数据使用 AES-256-GCM 加密；账户凭据加密存储。另内置 SSRF 防护、Docker 沙箱、AI 风险分类与频率限制等防护。

## 模型

**问：可以同时用多家模型吗？**
答：可以。添加多家服务商的模型，在输入框右侧随时切换。

**问：模型支持看图吗？**
答：在模型设置中为该模型开启「多模态能力」开关（保存时验证），并在输入框选择该模型。

## 其他

**问：如何联系支持 / 反馈 Bug？**
答：见 [关于与更新](/desktop/about.md) 中的官方文档、反馈、社区与联系方式。

**问：如何升级应用？**
答：关于页面点击「检查更新」，或通过系统软件源获取新版本。
