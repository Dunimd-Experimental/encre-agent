模型是 Agent 的"大脑"。在 **设置 → 模型** 中统一管理所有模型。

## 添加模型

点击「新建」，填写以下字段：

| 字段 | 说明 |
| --- | --- |
| 显示名称 | 你在列表中看到的名称（如 `DeepSeek`） |
| 模型 ID | 服务商的模型标识（如 `deepseek-chat`） |
| 服务商 | 模型提供方 |
| API 密钥 | 服务商平台申请的密钥 |
| Base URL | 接口地址（保存时会自动拼接 API 路径） |
| 最大 Token | 单次回复的最大输出长度 |
| 多模态能力 | 支持输入图片的模型开启此开关（保存时验证） |
| 推理等级 | 支持深度思考的模型可启用，输入框右侧可选档次 |

界面也提供「获取 API 密钥」和「查看文档」快捷入口。

![模型管理页面](/screenshots/models-list.png)

## 管理模型

- **启用 / 停用**：停用的模型不会出现在选择器里
- **编辑**：修改配置
- **删除**：移除模型（不影响服务商侧的密钥）
- 支持同时配置**多家服务商**的模型，在会话输入框处随时切换

Encre Agent 内置对 **31 家主流大模型服务商**的支持，一个应用即可统一管理。

## 选择模型的两种方式

1. **输入框右侧的选择器**：为当前会话挑选模型，随说随换
2. **自动化任务的「执行模型」**：为定时任务指定专用模型（见 [自动化](/desktop/automation.md)）

> [!TIP]
> 建议为多模态模型（如支持视觉的模型）开启多模态开关，否则即便模型支持，对话中也可能按文本处理图片。
