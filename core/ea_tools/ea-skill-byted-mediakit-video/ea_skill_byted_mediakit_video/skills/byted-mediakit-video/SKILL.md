# Video Skills

## Prerequisites

Before starting, you must read the contents of `./reference/shared.md`, which contains instructions on prerequisite checks, async task mechanisms, result queries, etc.

## Tool List

| Tool | Description | Parameter Declaration | Reference |
|------|------|----------|----------|
| analyze-video-highlights | Intelligently capture video "emotional peaks" and "key actions," outputting precise timestamps, highlight scores, OCR text, and visual description metadata for downstream flexible secondary development. Supports two analysis models: Miniseries and Game. Usage limit: max 100 videos per request, total duration no more than 300 minutes. | `video_urls:array<string>, model:string, mode:string, minigame_info?:object{name?:string, play_definition?:string, highlight_definition?:string}, callback_args?:string, client_token?:string` | [reference/analyze-video-highlights.md](reference/analyze-video-highlights.md) |
| analyze-video-storyline | Intelligently analyze film and TV content, generating structured storylines for smart editing, content retrieval, and interactive playback scenarios. Based on large model video understanding capabilities, it analyzes single or multiple long videos (e.g., movies, TV series), extracting and organizing them into a complete storyline. The storyline consists of a series of chronologically arranged clips and highlight storylines aggregated from those clips. Usage limit: max 30 videos per request, single video no longer than 2.5 hours. | `video_urls:array<string>, enable_snapshot?:boolean, callback_args?:string, client_token?:string` | [reference/analyze-video-storyline.md](reference/analyze-video-storyline.md) |
| asr-subtitles | Perform speech recognition on input video or audio, outputting timestamped subtitle segments. Supported formats: mainstream audio/video formats (mp4, mov, mp3, m4a, wav, etc.). Input: choose either video_url or audio_url. | `video_url?:string, audio_url?:string, content_type?:string, language?:string, enable_speaker_info?:boolean, enable_confidence?:boolean, callback_args?:string, client_token?:string` | [reference/asr-subtitles.md](reference/asr-subtitles.md) |
| enhance-video | Quality enhancement: provides a one-stop solution for quality improvement + super-resolution enhancement for AIGC / UGC / short drama / education / gaming / old film restoration scenarios. Powered by the AI MediaKit intelligent media processing engine, integrating video content understanding, intelligent quality metric decision-making, and multi-dimensional enhancement atomic algorithms to achieve comprehensive quality optimization. Supported formats: mainstream video formats such as mp4, flv, ts, avi, mov, wmv, mkv. Usage limit: single file no larger than 100G. | `video_url:string, scene?:string, tool_version?:string, resolution?:string, resolution_limit?:integer, fps?:number, callback_args?:string, client_token?:string` | [reference/enhance-video.md](reference/enhance-video.md) |
| enhance-video-generative | Generative video enhancement restoration (generative_video_restoration) is a generative video repair technology based on a Diffusion-based Large Model. It not only restores damaged pixels but also leverages rich visual priors accumulated through large-scale pre-training to proactively complete details, understand semantics, and generate realistic, natural, high-fidelity video content. | `video_url:string, resolution?:string, bitrate_level?:string, fps?:number, callback_args?:string, client_token?:string` | [reference/enhance-video-generative.md](reference/enhance-video-generative.md) |
| erase-video-subtitle | Intelligently detect and erase existing hardcoded subtitles from video frames while preserving the original background. Supported formats: mainstream video formats such as mp4, flv, ts, avi, mov, wmv, mkv. | `video_url:string, callback_args?:string, client_token?:string` | [reference/erase-video-subtitle.md](reference/erase-video-subtitle.md) |
| erase-video-subtitle-pro | Achieve high-quality, traceless erasure of subtitles in videos, restoring the video frame to the greatest extent. Supported formats: mainstream video formats such as mp4, flv, ts, avi, mov, wmv, mkv. | `video_url:string, mode?:string, output_encode_mode?:string, erase_ratio_location?:array<object{top_left_x:number, top_left_y:number, bottom_right_x:number, bottom_right_y:number}>, callback_args?:string, client_token?:string` | [reference/erase-video-subtitle-pro.md](reference/erase-video-subtitle-pro.md) |
| generate-highlights-microdrama | Deeply understand short drama characters, plots, and storylines, automatically extract highlight clips and mix them into marketing videos. Supports StorylineCuts mode with optional "three-element short drama" visual templates, outputting highlight reels, episode previews, etc. Supports detailed storyboard output. Usage limit: max 100 videos per request, total duration no more than 300 minutes. | `video_urls:array<string>, mode?:string, enable_generate_video?:boolean, enable_return_poster?:boolean, edit_param?:object{mode:string, template_edit?:object{template?:string, title?:string, hint?:string}}, highlight_cuts_param?:object{enable_storyboard?:boolean, min_duration?:number, max_duration?:number, max_number?:integer, cut_mode?:string}, opening_hook_param?:object{enable_opening_hook?:boolean, min_duration?:number, max_duration?:number, min_clip_duration?:number, min_score?:number}, callback_args?:string, client_token?:string` | [reference/generate-highlights-microdrama.md](reference/generate-highlights-microdrama.md) |
| generate-highlights-minigame | Identify core gameplay and highlight events (such as combos, level completion, extreme maneuvers, etc.) from mini-game screen recordings, quickly generating video assets for user acquisition. Supports providing game name, gameplay description, and highlight definition to assist the model in more accurate recognition. Usage limit: currently only supports single video input. | `video_urls:array<string>, mode?:string, enable_generate_video?:boolean, minigame_info?:object{name?:string, play_definition?:string, highlight_definition?:string}, callback_args?:string, client_token?:string` | [reference/generate-highlights-minigame.md](reference/generate-highlights-minigame.md) |

Supported formats: mainstream video formats such as mp4, flv, ts, avi, mov, mkv, wmv. | `video_url:string, format?:string, callback_args?:string, client_token?:string` | [reference/matte-greenscreen-video.md](reference/matte-greenscreen-video.md) |

Supported formats: mainstream video formats such as mp4, flv, ts, avi, mov, mkv, wmv. | `video_url:string, format?:string, callback_args?:string, client_token?:string` | [reference/matte-portrait-video.md](reference/matte-portrait-video.md) |

Usage limit: single video duration no longer than 2 hours. | `video_url:string, enable_clip_fade?:boolean, segment_threshold?:number, min_duration?:number, max_duration?:number, callback_args?:string, client_token?:string` | [reference/segment-scenes.md](reference/segment-scenes.md) |
