# Pre-Launch Checklist

The following are preparations that need to be completed by the user before going live with DouyinPay:

**1. Register on DouyinPay Merchant Platform, Get Merchant ID**
  - Merchant registration guide: https://pay.douyinpay.com/wiki/63a0142c70f838021f2984ab/63a0144ce0c64802240b6638

**2. Enable Products**
  - Self-service product activation guide: https://pay.douyinpay.com/wiki/63a0142c70f838021f2984ab/661e86d884e786031dc1ea06

**3. Create App on Douyin Open Platform, Get AppID (ClientKey)**
  - Open Platform AppID creation guide: https://pay.douyinpay.com/wiki/63a0142c70f838021f2984ab/63a016cee0c64802240b6b81

**4. Bind AppID**
  - AppID association management: https://pay.douyinpay.com/wiki/63a0142c70f838021f2984ab/661e870bf5953103033c3ff5

**5. Configure Key Certificates**
  - Certificate key guide: https://pay.douyinpay.com/wiki/66aa57118a7da602efb9bc2f/66aa579b0b96c602fc4d60e0

**6. Configure H5 Payment Domain and JSAPI Authorization Directory (as needed)**
  - Configure H5 payment domain (for H5 payment): https://pay.douyinpay.com/wiki/63a0142c70f838021f2984ab/69294c24d51d13056594d27a
  - Configure JSAPI payment authorization directory (for JSAPI payment): https://pay.douyinpay.com/wiki/63a0142c70f838021f2984ab/693fc26cfa26da055c7632b8

**7. Add Split-Account Recipients (as needed)**
  - If merchant split accounting is involved, add split-account recipients before calling the split request API: https://pay.douyinpay.com/wiki/639fd48f17c2f3021d237f61/6949394b7f605b05358e83b4
