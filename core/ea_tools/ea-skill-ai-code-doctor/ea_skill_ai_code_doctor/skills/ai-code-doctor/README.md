# AI Code Doctor

一个面向 Python 代码的双层审查 Skill：第一层检测 AI 生成代码特有的"坏味道"，第二层对热点路径做运行时性能体检，最后输出优化代码与自包含诊断报告。改动是否写回原文件由用户确认，安全网依赖 git。

## 它解决什么问题

AI 生成的 Python 代码量大且增长快，但带有独特缺陷：过度防御、冗余样板、复制粘贴、过度工程化、幻觉 API、风格漂移；同时藏着真实的性能隐患（N+1 查询、可降复杂度、阻塞 I/O 等）。规则型 linter 抓不到语义层的 AI 异味，通用 AI 助手往往只给笼统建议。本 Skill 用"先闻味、再探性能、最后开方"的流程，给出可执行、带证据、行为等价的优化方案。

## 能力边界

- 只审查 Python 代码（其他语言会拒绝并说明）。
- 重构而非重写：保留可观测行为，不改外部接口签名，不改业务逻辑。
- 缺失上下文时不臆测，向用户提问。
- 性能收益优先给实测数据（代码可跑时），不可跑时给理论量级预估。

## 双模式入口

- **定点模式**：用户指定文件 / 函数 / 行范围，直达审查。
- **全量自审模式**：用户只交出文件或项目、未指明位置时，Skill 先用静态分析定位热点（圈复杂度 Top-N + I/O/DB 调用点 + 枢纽函数），再对热点做双层审查。

## 工作流

1. 接收代码，判定入口模式。
2. （仅全量模式）侦查定位热点。
3. 第一层·AI 异味自审：六类异味扫描。
4. 第二层·性能深度体检：七类性能反模式扫描，配静态分析硬数据。
5. 综合诊断：按严重度排序，每条「问题 → 影响 → 方案 → 收益」四段式，计算健康度评分；优化后运行接口兼容性检查。
6. 开方：输出优化代码 + 诊断报告 + 对话摘要。

## 输出物

跑完后用户拿到三层输出：

1. **对话层（即时）**：一句话健康度总评、Top 3 关键发现、产物文件指引。
2. **`optimized_code.py`**：完整的优化代码，保留接口签名，关键改动处注释标注；只有编译和导入烟测通过后才标记为可运行。
3. **`audit_report.html`**：自包含诊断报告，含健康度评分、问题清单（④/③ 标签）、优化代码、before/after 改动对照、运行前提和取舍说明。可分享、可归档。

## 改动是否写回原文件

默认**不修改**原文件。若输入是磁盘上的文件，Skill 会先列出修改方案并询问用户，经用户明确确认后才写入原文件。安全网依赖 git 提交历史（或要求 AI 改回去），不额外生成 `.bak` 备份文件，避免污染仓库。粘贴片段场景下没有原文件可改，只输出新文件与报告。

## 六类 AI 异味

1. 过度防御性编码（吞异常、冗余 None 检查）
2. 冗余样板 / 废话注释
3. 复制粘贴模式
4. 过度工程化（单一使用的工厂/抽象类）
5. 幻觉 API 调用
6. 风格漂移（命名/格式构造不一致）

## 七类 Python 性能反模式

1. ORM N+1 查询
2. 可降复杂度（O(n²)→O(n)）
3. 串行阻塞 I/O
4. 冗余重复计算
5. 低效数据结构（list 做 in 查找）
6. 循环内字符串拼接
7. 大文件一次性载入

## 使用方法

本 Skill 遵循通用 Skill 协议，可安装到任何支持 Skill 机制的 AI 编码助手中。安装后无需手动调用——当用户提出 Python 代码审查、优化、检查类请求时，助手会依据 SKILL.md 中的描述自动识别并启用本流程。

分析脚本和接口检查脚本只使用 Python 标准库。被审查代码可能依赖第三方包；优化代码只有在当前环境编译、导入烟测均通过时才能标记为可运行，否则必须在对话和报告中列出缺失包或其他运行前提。

典型用法：

- 把代码贴给助手，说"帮我审查这段 Python 代码"或"看看这个项目哪里能优化"。
- 也可以指定位置："检查 `process_order` 这个函数"（定点模式）。
- 助手会跑完双层审查，给出优化代码与诊断报告；若要改原文件，需你确认。

## 静态分析脚本

`scripts/analyze.py` 可独立运行：

```
python scripts/analyze.py <文件或目录路径>
```

输出 JSON：每函数圈复杂度、重复代码块、带限定名的枢纽函数、去重后的 I/O/DB 调用点、文件级与汇总摘要。项目扫描默认排除 `.git`、`.venv`、`site-packages`、`node_modules`、`__pycache__` 等依赖或缓存目录。对 UTF-8 BOM、语法错误、空文件、非 Python 文件均不崩溃，始终输出合法 JSON。

比较优化前后的接口：

```text
python scripts/check_interface.py <原文件.py> <优化文件.py>
```

非零退出表示存在缺失或变更的顶层函数、类、类方法或参数签名；在修复兼容性前，不得将优化代码标记为可运行。

安全生成 HTML 报告：

```text
python scripts/render_report.py <结构化报告.json> <audit_report.html>
```

渲染脚本校验健康度、问题列表、运行前提和取舍说明等字段，并统一转义文件名、代码、诊断文本及其他输入。不要手工替换模板占位符或拼接原始 HTML。
